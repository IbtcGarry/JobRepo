# JobTest frontend (Angular)

The website: Angular 21 + TypeScript, talking directly to Appwrite Cloud.

```bash
npm install
npm start                    # http://localhost:4200
npx ng test --watch=false    # unit tests
npx ng build                 # production build (what Vercel runs)
```

- How the code is organised and how to change it: [`../DEVELOPING.md`](../DEVELOPING.md)
- Architecture diagram: [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)
- Every file under `src/app/` starts with a comment saying what it does.

# JobRepo

A job board for job seekers and employers (inspired by LinkedIn and YC's Work at a Startup).

- `frontend/` — Angular app (TypeScript), deployed to Vercel as **JobTest** — https://jobtest-beta.vercel.app
- `functions/` — Appwrite Functions (TypeScript / Node.js)
- `appwrite.json` — Appwrite project config (tables, buckets, functions)

See [CHECKLIST.md](CHECKLIST.md) for what is done and not done, and [ROADMAP.md](ROADMAP.md) for the full plan.

## Run locally

```bash
cd frontend
npm install
npm start
```
